## 受け入れ条件

依頼書の12項目すべてが必要。ブラウザのiPhoneエミュレーションは実機検証の代替ではない。全文許諾のない初期配信元はR05の外部遷移方式を採る。広告なし全文閲覧を全配信元に保証しない。

## 不明点・公開前のゲート

- RSS購読導線は確認できるが、一般公開サービスによるタイトル集約の明示的許諾と全文転載許諾は別途確認が必要。個人試用から始める。
- 権利者への問い合わせ・一般公開の判断は未実施。全文転載機能は有効にしない。
- 商標・ドメインの権利調査はこの開発の完了条件に含めず未確認として引き継ぐ。
- 保存対象はメタデータであり、元サイト本文・画像のオフライン保存ではない。

## 2026-10-27 追加入力: 個人用アプリ内リーダー

利用者が外部サイトで広告が残ることを指摘し、「どうでもいいから広告なしで見れるように直して」と本文閲覧の修正を指示。個人用プレビューに以下を追加する。R05の一般公開時の権利確認を完了と扱わず、当初の受け入れ条件を削除しない。

| ID | 追加要件 | 検証 |
|---|---|---|
| READ01 | 対応2サイトの記事をアプリ内で読み、外部へ自動遷移しない | 実ページ / E2E |
| READ02 | 固定の本文要素からテキストと検証済み画像だけ抽出し、広告・埋め込み・スクリプトは描画しない | reader unit / network E2E |
| READ03 | 記事画像は明示操作後のみ、本文はIndexedDBで24時間・100件まで利用 | consent / offline E2E / PWA |
| READ04 | 既知のRSS記事だけ取得、リダイレクト・アクセス拒否・構造不一致は失敗表示。任意URLプロキシやアクセス制限突破は作らない | reader unit |
| READ05 | 認証付き個人用Preview限定。Productionの本文APIは拒否。一般公開の転載許諾は別途確認 | handler unit / deploy configuration |

上記の個人用読書表示についてはADR 003に設計・制約を記録する。本文キャッシュを追加するため、初期版の「保存対象はメタデータのみ」はお気に入り・既読の保存形式を指し、読書キャッシュは別に管理する。
