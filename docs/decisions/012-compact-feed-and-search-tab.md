# ADR 012: ホームをコンパクトな記事一覧にし、検索を独立タブへ移す

日付: 2026-10-28。状態: 採用。

利用者は現在の見た目を評価しつつ、記事行が厚く選ぶまでのスクロールが多いと指摘。説明帯を消し、起動直後の新着/人気切替と別タブの検索を希望した。

配色・書体・ロゴを維持し、記事タイトル→出典/日時の2段を基本とする。最大3行のタイトルと単一メタデータ行、短い余白で一覧性を上げ、記事と保存の44px以上の操作領域を維持する。長い見出しをアクセシブル名とReaderでは省略しない。出典や実際の順位/ブックマーク数を消したり人気スコアを作ったりしない。

ホーム上部へ新着/人気を置き、カテゴリ/日付/未読などはdetailsへ収納。welcome-cardを除去し、検索フォーム/マイ検索/検索結果を検索タブに移す。既存カテゴリタブを残して5タブとし、ホームと検索の並び順を分離する。通常の検索はタブ往復で維持、隠し候補/語は検索タブを離れると消す。サーバーAPI・記事認可・本文cacheは変更不要。
