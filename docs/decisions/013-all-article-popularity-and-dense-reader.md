# ADR 013: 人気を全取得記事へ広げ、本文の余白を詰める

日付: 2026-10-28。状態: 採用。

利用者は人気11件が少なく全件を希望し、本文の行間も広いと指摘。旧表示の11件は配信元ウィジェット5＋6件だった。ハムスターのlimit=100を観測しても10件、アルファは6件で、公開された順位だけを引き延ばすと全記事の根拠を作れない。

人気の候補をRSS新着全件＋公開人気候補（ハムスター10/アルファ6）へ広げ、公式はてなブックマーク数で全件を並べる。0件を残し、同数は新着。指標取得失敗時は全候補を新着で表示し理由を明示。日付指定時はarchive全件を対象にする。全過去記事の総合順位とは表示しない。新たな無制限巡回/任意URL取得は不要。

元のソースcacheを維持し、人気集合のsha256を認可参照としてサーバーに保存。記事・配信元・元取得日時の完全照合、24h有効を守り、保存から開く参照も端末に保持。cacheだけから照合してクライアントのハッシュを取得許可証にしない。

本文は表示時にだけ連続空行を整理し、文字サイズを維持して行高1.55・段落下6pxへ変更。本文v3を維持して保存済みの本文にも反映する。本文/番号/URL/字下げとメディアリンクを保持し、広告フィルタや画像選別の基準は変更しない。
