# ADR016: 記事原画像とインライン写真特集

2026-10-29 採用。ADR014/015の検索サムネイルだけの閲覧を、利用者の写真閲覧指示に沿って拡張。

検索192pxクロップは記事の本来の写真ではなく、幅だけ広げると画質も画角も改善しない。Yahoo記事内で明示されたview画像へ切替。指定記事の本文にあるMANTANの写真特集が主要な写真先だったため、親記事から実在する特集だけを開く固定ソースの写真リーダーを追加する。

追加指示で、特集も本文写真の一覧と並べてすぐ見たいとの要望。別ブラウザ/ダイアログへの移動を必須とせず、主特集を自動で記事内に表示する。サムネイル/前後/スワイプで選び、写真が長くなってもニュースへ直接移動できる固定ボタンを置く。

記事と特集、特集と写真ページの紐づけを検証する。MANTANの明示されたsrcsetから大きい画像を使い、画像連番や高解像度URLを推測しない。広告・ランキング・関連画像を除外。ブラウザへ広告scriptを持ち込まず、記事全文を応答に含めない。既存個人用Previewの保護と本文v3を維持し、一般公開許諾が確認済みとは判断しない。


実通信でMANTAN画像の参照元なし403と、画像を明示する実在の写真ページ文脈による200を確認。専用の同一オリジン画像APIを採用する。クライアントは画像URLもRefererも指定できず、記事→特集→一覧内写真の検証済みメタデータからサーバーが解決する。固定CDN・MIME/サイズ制限・Preview認証・私的キャッシュで任意URLプロキシにしない。
