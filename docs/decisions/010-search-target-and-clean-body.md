# ADR 010: 配信元候補をタイトル・おすすめ除外本文で再照合

日付: 2026-10-28。状態: 採用。

利用者から「おすすめリンク由来の無関係な記事が混ざる」と報告。実アルファ本文内にmanual-relatedの別記事見出し一覧を確認。配信元検索は候補取得に限定し、結果の一致はアプリで判定する。

初期値をタイトルのみとし、本文を含む検索へ明示的に切替可能にする。スペース区切り語はAND。本文は個人用Previewでのみ取得し、固定本文rootの通常文字列から全リンク文字・関連記事/おすすめ/広告/非表示領域を除く。表示リーダーv3のキャッシュから全文を流用せず独立の厳密抽出/キャッシュを使う。リンクされた引用の単語まで対象外になる制限を説明する。

タイトル一致だけなら追加取得は不要。本文確認は個別6秒/全体22秒/6並列/2MB、結果テキスト24時間・失敗1分で再利用。確認できない候補は表示せず件数を明示し、再試行可能にする。空ページでも先があれば移動可能。記事を隠すNG/配信元設定や、新着/実ブックマーク順、日付を絞らない検索を維持する。

ヒントも新しいタイトルAND判定で実検索して再集計。旧11候補中、各3件以上を確認できた美脚7件・スレンダー3件・ルーズソックス4件の3候補を残す。観測日は2026-10-28、件数は提供された最初のページ内での見出し除外後の観測値であり総数ではない。
