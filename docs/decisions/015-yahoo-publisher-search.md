# ADR015: Yahooの人物検索をRSS絞込みから公開検索候補へ

2026-10-29 採用。ADR014/YAHOO04の検索方式を置換。

「岡田紗佳」で0件という報告に対し、Yahoo側で候補243/先頭50、タイトル一致25、抜粋含む50を実確認。RSS450件を検索と呼ぶだけでは目的を満たさないため、固定公開検索ページの実候補から照合する。

取得は公開HTMLのserialized search.contentsだけ。ニュースID/URL/照合語を検証し、広告枠/viewType1・ランキング・おすすめstateを無視。script実行やYahoo内部/api、アクセス制限回避は行わない。先頭50候補からの照合であり、243件全取得とは表示しない。試した公開ページパラメータは先頭候補のままで、後続取得を実装できたと偽らず外部検索へ案内する。

検索サムネイルと短い抜粋だけを表示し、本文全文取得は追加しない。出典と元記事リンク、画像allowlist、認証付きPreviewを維持。個人利用の私的複製例外を否定せず、法律上の例外とサービス利用条件、サーバーでの具体的な複製/送信を分けて説明する。
