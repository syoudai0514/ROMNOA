# ADR 009: 配信元の全期間検索と確認済み検索ヒント

日付: 2026-10-28。状態: 採用。

利用者は新着以外の過去記事検索、検索/日付UIの改善、公開のマイ検索、PINで開く隠しヒントを希望。検索時には期間を絞らず、新着/人気を選択するよう指定した。

両サイトの実在する/search/<語>?p=Nを使用し、RSS内のタイトルフィルタと分離する。実検索では年単位で古い記事が見つかった。一方で2010/2015年の日付別・月別ページは配信元404だったため、存在しない一覧を作らず全期間キーワード検索へ案内する。

人気は検索ページ内の実際のはてなブックマーク数を採用し、独自スコアは作らない。配信元の検索インデックス全体や全過去記事の順位を取得したとは表示しない。指標障害時は0を捏造せず新着で表示する。

マイ検索は登録語を端末に保存する通常機能。隠し候補はサーバーPIN照合後にだけ配布し、平文PINはフロント/リポジトリへ置かない。既存Preview認証を維持する。表示用ロックのため、強固なアカウント認証や匿名閲覧と同一視しない。記事の履歴/保存は共通。

ヒントは成人の非露骨な服装・写真集の語に限定。候補18語を実検索し、見出し除外後に3件以上確認できた11語だけ採用。確認日/件数を記録し、保守用check:hintsで再確認可能にする。外部AI APIは不要。
