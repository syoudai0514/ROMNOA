# ADR 008: 配信元の順位と日付別アーカイブを探索に使う

日付: 2026-10-28。状態: 採用。利用者が人気順・日付指定を希望。

## 判断

独自の人気スコアではなく配信元自身の公開ランキングを使う。ハムスター速報はウィジェットの直近1週間・5件、アルファルファモザイクは公開TOP6。集計方法の異なる順位はサイト別に表示し、総合順位に換算しない。数値が確認できないPVを表示しない。

日付フィルタを新着RSSの範囲に限定せず、確認できた両サイトの日付別公開ページを取得する。1日単位、日本時間、固定ホストとパスだけを許可。現在人気との併用は記事IDを日付一覧と照合する。過去の人気ランキング履歴を取得したとは表示しない。

既存のArticle/設定/本文スキーマを変えず、別API・キャッシュ・順位配列を追加する。本文を開く権限はクライアントの日付ではなく、新鮮なサーバー取得一覧内のID一致による。既存の本文キャッシュ・親記事の経路を維持する。

## 影響

公開メタデータだけを探索APIに返し、元のランキングスクリプト・広告・本文HTMLを実行/描画しない。元ページの削除/非公開/ページ送り/構造変更で欠落する可能性がある。上限やページ送りは一部取得と説明する。10分/過去日24時間キャッシュ、8秒・2MB・100記事/配信元で負荷を制限する。Preview認証を維持。一般公開の利用条件とiPhone実機検証は別途必要。
