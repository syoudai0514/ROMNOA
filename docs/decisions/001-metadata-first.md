# ADR 001: 許諾確認までメタデータ専用とする

採用日: 2026-10-20

状態: 個人用プレビューは2026-10-27の[ADR 003](003-personal-reader.md)で更新。一般公開の権利確認に関する原則は維持する。

RSSで全文が配信されていることと、サービスで再配信してよいことを区別する。ハムスター速報・アルファルファモザイクは公式ページにRSS購読導線があるが、全文転載の明示的許諾は確認できなかった。初期版ではdescription/content:encoded/画像をレスポンスに含めず、タイトル・日時・出典・カテゴリだけを集約する。詳細で本文の閲覧先と外部広告の可能性を示す。

許諾取得時は記録URL・権利範囲・期間・撤回方法をソース台帳に追加し、本文専用スキーマ/サニタイズ/画像読込の同意/UI/テストを追加する。設定フラグ一つで無条件の全文取得へ切り替えられる設計にはしない。
