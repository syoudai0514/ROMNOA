# ADR 011: 少数時に過去ページを自動確認し、保存・履歴も検索に含める

日付: 2026-10-28。状態: 採用。

「岡田紗佳」で3件しか出ず、保存している記事がないとの報告。配信元1ページの52候補からタイトル3件だけが一致する一方、アルファ2ページに4件、3ページに10件の別のタイトル一致が存在した。日付条件を付けてはいないが、1ページずつの置換表示と総数に見える件数が誤解と取りこぼしを招いていた。

候補の一致確認・おすすめ除外は維持し、最大5ページ/新規20一致を目安に次を自動取得して逐次累積する。さらに過去を探す操作で継続可能。APIはページ単位の許可リスト・取得制限・cacheを変えず、候補日付の最古/最新を付ける。UIは全期間条件と確認済み範囲、累計件数、検索中、続行可能、末尾を区別する。最後のページまで確認しても未索引記事の網羅は主張しない。

端末の保存・履歴のタイトル一致を重複なく加える。本文cacheのおすすめリンクを検索へ再混入させず、日付不明を除外せず、人気数を捏造しない。ページごとのcollectionを記事IDに紐づけてReaderへ渡し、認可を緩めない。後続取得失敗時は確認済み結果と未取得cursorを維持する。
