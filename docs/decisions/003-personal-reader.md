# ADR 003: 個人用プレビューにアプリ内リーダーを追加

採用日: 2026-10-27。ADR 001の「メタデータのみ」は個人用プレビューではこの判断へ移行する。一般公開時の転載・配信許諾を確認済みと扱うものではない。

利用者から「広告なしで見れるように直して」と本文閲覧の実装を改めて明示的に指示された。外部サイトへのリンクとSafari設定の案内では要求を満たさないため、認証付きの個人用プレビューに読書表示を実装する。本文利用の権利条件を確認した一般公開サービスの完成とは区別する。

## 採用する動作

- 記事を開く操作で、現在の許可済みRSSにある記事の公開ページを取得する。対応はハムスター速報の数値記事パスとアルファルファモザイクの数値記事パスだけ。
- サイトごとの本文要素のみを解析。プレーンテキストと検証した記事画像URLの配列へ変換する。元のHTML・JavaScript・CSS・iframe・動画・広告欄・関連記事は返さない。
- 画像は初期状態で読み込まず、利用者の「記事の画像を表示」操作後に許可した画像CDNのみ読み込む。
- 外部サイトへの自動遷移を廃止。元記事は折りたたんだ補助導線から明示的に開く。
- 取得した本文をVercel Runtime Cacheと端末のIndexedDBで24時間まで利用。端末本文キャッシュは最大100件。お気に入り・既読・設定の既存保存形式を維持する。

## 制約

- Vercel Authenticationが有効なPreviewで運用する。コードもVERCEL_ENVがpreview以外なら本文APIを403にする。アクセス保護を外さない。一般公開・Production対応には利用条件・権利処理・認証を別途確認する。
- 有料・認証・アクセス制限の突破、User-Agent偽装による回避、リダイレクト先の取得はしない。403/リダイレクト/本文構造不一致はエラー表示とし、ページ全体を代わりに埋め込まない。
- 原文の文章・画像の権利は各権利者に帰属し、配信元名・元記事リンクを保持する。公開サイトの包括的な再配信許諾を取得したという表示はしない。
- 全ページの完全抽出、分割記事の後続ページ、配信期間外の記事、iPhone実機動作は保証しない。取り出せないページはエラーを明示する。

## 検証

実ページの本文抽出、アプリ内での閲覧、外部自動要求0、画像の明示操作、オフライン本文表示、取得失敗時の自動遷移なし、SSRF/HTML実行防止、Production拒否を確認する。
