# ADR 004: 画像を中心に表示し、関連記事を安全に辿る

採用日: 2026-10-27。利用者の追加指示で、ADR 003の画像同意ボタンと関連記事の全面削除を変更する。

画像の閲覧を主目的とするため、記事画像を初期表示し、拡大・画像前後移動・任意の本文表示を提供する。記事本文の固定領域と出典フォルダを照合し、広告/アフィリエイト/追跡/不明なリンク画像を読み込まない。別記事への誘導画像は本文から分離する。配置とリンク先に基づく規則判定であり、画像内容と題名の意味的一致や画像の真贋を保証するAI判定ではない。

編集された関連記事や直リンクを残し、対応2サイトのタイトル・サムネイルを別領域に表示する。クリック時だけ本文を取得する。サーバーに保存した24時間以内の元記事ドキュメントに対象URLが存在することを必須にし、クライアントが任意URLを送っても取得しない。新着RSSから消えた記事も、その確認済み経路で辿れる。広告リダイレクトや未対応サイトを取得対象へ広げない。

元記事へ戻る履歴とスクロールを維持し、保存・既読・NGワード・非表示配信元を引き継ぐ。キャッシュschemaVersionを2へ更新し、旧版の未分類本文画像を再利用しない。本文80画像・関連記事12件・履歴経路50件を上限とする。

一般公開の利用許諾やiPhone実機確認を完了扱いにしない。既存の認証付きPreviewとProduction拒否を維持する。
