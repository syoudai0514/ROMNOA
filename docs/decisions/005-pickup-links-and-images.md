# ADR 005: Pickup一覧を本編と区別し、本文リンクとX画像を保持する

採用日: 2026-10-28。

利用者から「画像が一覧のように並ぶ」「モザイク」「リンクを押しても反応しない」とスクリーンショット付きの報告を受けた。対象の11124247.htmlを調べると、Pickup一覧の見出し・見出し用画像・別記事リンクが並び、本編は11089177.htmlへ直接リンクされていた。従来の抽出は一覧を通常記事として扱い、a要素を文字だけに変換していた。また本編にはpbs.twimg.com/media/の画像10件があり、従来の画像許可リストがそれらを除外していた。

一覧はpageKind=roundupとして本編へのカードを表示する。本文画像を並べたギャラリーとは扱わない。daily_popular_title内の直接記事リンクを優先し、汎用的な「続きを読む」でタイトルを上書きしない。既存の固定記事パスと親キャッシュによる取得認可を維持し、アンテナや任意URLをサーバーで辿らない。

元ページを開くリンクを常時表示し、関連記事にも直接リンクを付ける。本文のリンクを安全なhttp(s) URLとして保持し、Reactのa要素で表示する。外部ページへの自動遷移はせず、利用者の操作で開く場合には広告の可能性を明示する。

Xの静止画像は固定ホスト・mediaパス・形式・パラメータを検証したものだけを追加する。本文の画像があれば見出し用の画像を優先しない。モザイクを編集・推測復元する機能は実装しない。本文スキーマ/サーバーキャッシュをv3へ更新し、旧版の不完全な本文を表示し続けない。PWAは自動更新を使用する。

一般公開の権利条件とiPhone Safari実機確認は引き続き未完了。認証付きPreviewとProductionの本文API拒否を維持する。
