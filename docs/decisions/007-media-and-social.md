# ADR 007: 記事メディアのネイティブ再生とSNS対応範囲

日付: 2026-10-28。状態: 採用。利用者の動画・GIF・SNS画像に関する追加指示。

## 問題と判断

MP4を外部aとして描画していたため記事内で再生できなかった。動画広告の除外と記事の動画再生を区別し、許可した直接メディアだけをHTML videoで再生する。controlsとplaysInlineを使用し、通常動画の自動再生はしない。Xのアニメーション動画とImgur gifvはmuted/loopで再生し、端末の動きを減らす設定を尊重する。

本文スキーマはv3のlinksを再利用する。サーバー/端末のキャッシュや既知記事の認可を破棄しない。固定本文から抽出し広告領域を除外する原則、Production本文API拒否、Preview認証保護を維持する。

SNSは記事に含まれる公開画像・動画のCDN URLを表示する。署名付きInstagram CDN URLは署名を維持。公開投稿リンクだけからの取得は未実装。公式oEmbedを実際に調べたが、確認したX/Instagramの応答には直接画像URLがなかった。埋込SDK/iframeで広告や外部スクリプトを実行する方式、非公式プロキシ、ログイン突破は採用しない。

## 影響・検証

削除・公開制限・署名期限・ブラウザのコーデック対応で再生不可になり得る。ネイティブプレーヤーの読込失敗/再生拒否と再試行を画面に示す。MP4/アニメーション/GIFは自己生成の小さなメディアで実際の復号・時間進行・表示フレームを検証する。外部CDNは別途実通信で確認し、fixture成功を実サイト再生成功と混同しない。iPhone実機は未確認。
