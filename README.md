# ROMNOA — Read freely.

ロムノア。「読みたい話題だけ、ノイズなく。」iPhoneを優先した、まとめ記事の画像・動画・本文を読むPWAです。

**認証付きの個人用プレビューです。** 記事をタップするとアプリ内リーダーで本文を表示し、広告・ポップアップ・外部スクリプトを描画しません。記事内の対応MP4はアプリ内プレーヤーで再生でき、GIFも表示します。記事画像を選別して最初に表示し、タップで拡大できます。関連記事のサムネイルは別の記事として分け、アプリ内で読み進められます。Pickupなどの記事紹介一覧は本編と区別し、タイトルから本編を開きます。本文中の画像URL（Imgur等）も自動で写真を表示し、タップはアプリ内の拡大になります。既知の関連記事はアプリ内で読み進められ、明示的な「元ページを開く」から元サイトも開けます。一般公開の全文再配信許諾とiPhone実機確認は未完了のため、Phase 1全体の完成とはしていません。

## 起動

Node.js 24 と npm が必要です。

```sh
npm ci
npm run dev
```

Viteの開発サーバーがUIと `/api/articles`・`/api/reader` を提供します。VercelではNode.js Functionを使用します。外部DBやアプリAPIキーの設定は不要です。プロキシ環境のNode.jsでは、その環境の指定に従い `NODE_USE_ENV_PROXY=1` を利用してください。

## 実装内容

- ハムスター速報・アルファルファモザイクの実在するRSSをサーバーで統合
- 新着/未読優先/カテゴリ順、人気順（全取得記事の実ブックマーク数）、日付指定、全期間の過去記事検索、カテゴリ選択
- 保存/既読/閲覧履歴、NGワード、配信元の表示切替、類似タイトルの折りたたみ
- ライト/ダーク/端末設定、文字サイズ、記事詳細と元記事導線、前後移動、アプリ内スクロール復元
- ロゴ/アイコン/PWA、オフライン用アプリシェルと記事メタデータキャッシュ
- 固定フィード許可リスト、取得制限、XML/XSS対策、障害分離とキャッシュ
- アプリ内本文リーダー（個人用Preview限定）、記事画像の自動表示・拡大・広告/誘導画像の分類、本文のIndexedDBキャッシュとオフライン閲覧

保存・設定は端末のブラウザ内だけに保持します。お気に入り・既読は既存のメタデータ保存を維持し、読んだ本文を別のIndexedDBに最大100件・24時間キャッシュします。画像・動画自体はオフライン保存しません。本文の画像は配信元CDNと検証したX画像（pbs.twimg.com/media/）・Instagramの直接画像CDN URLを表示します。投稿URLだけからの写真・動画取得は未対応です。外部SNSのウィジェットやSDKは読み込みません。本編画像があれば見出し画像を優先しません。キーワード検索は日付指定と独立して両配信元の過去記事検索を使い、RSS外も探せます。検索結果はページ送りでさらに遡れ、各ページ内で新着順・実際のはてなブックマーク数順を選べます。日付指定は配信元の日付別公開ページを使いますが、古い日付の一覧が公開されていない場合はその旨を表示します。ホームの人気順は、新着の全記事と配信元の人気候補をまとめ、実際のはてなブックマーク数で並べます。同数は新着順、0件の記事も含めます。日付併用はその日に取得できた全記事が対象で、過去のランキング再現ではありません。全サイト横断検索、過去の人気順位、AI推薦、アカウント、端末間同期はありません。

本文APIは現在のフィード、24時間以内の本文キャッシュ、サーバーが確認済みの関連記事・人気・日付一覧が対象です。対応は上記2サイトの固定記事パスです。関連記事は新着RSS外でも辿れ、元の記事へ戻れます。画像の内容と見出しの意味的な一致を保証するAI判定ではありません。配信期間外・アクセス拒否・ページ構造の変更時は本文を取得できない場合があります。元記事は補助リンクから任意に開けますが、その場合は広告が残ります。

## 人気順・日付指定

ホーム上部の「人気」をタップ（詳細な並び替えは「カテゴリ・日付」を開く）。新着の全記事＋配信元人気候補を、実際のはてなブックマーク数順に表示します。0件でも除外せず、取得失敗時も全記事を残して新着順へ戻ります。対象は取得できた記事で、全サイト・全過去記事の総合順位ではありません。

「掲載日」で日付を選択して「表示」。年・月から選べるカレンダー、今日/昨日/1週間前/1か月前/1年前、前後日/解除に対応します。日本時間で扱います。2005年1月1日から今日までを指定可能ですが、削除・非公開・掲載前の記事や配信元が返さない記事は取得できません。ページ送り/取得上限がある場合は一部取得と表示します。過去日の一覧は最大24時間、今日/人気は10分キャッシュします。端末には最近8条件を24時間保持します。

下部（デスクトップでは左）の「検索」タブで名前・キーワードを入力し、検索対象を「タイトルのみ」（初期値）または「本文を含む」から選び「検索」。複数の語はすべて含む記事だけを表示します。本文検索では配信元の候補を記事本文で再確認し、おすすめ欄・関連記事・広告・リンクの文字を除きます。確認できなかった記事は表示せず件数を案内します。本文確認には最大約35秒かかる場合があります。日付指定は解除され、配信元が検索対象にしている全期間を探します。少数の結果では次の検索ページも自動で確認して一覧に追加します。「さらに過去の記事」で続けて遡れます。画面に確認済みの日付範囲・ページ数を表示し、件数は全期間総数ではなく見つかった累計です。保存・履歴もタイトル一致なら日付不明を含めて補完します。人気順は**ここまで取得した記事内**のはてなブックマーク数順で、全過去記事の総合順位ではありません。取得できない指標をゼロと扱わず、新着順の表示と理由を示します。検索語は自動で端末に履歴保存しません。

「マイ検索」は通常機能です。自分で登録した女優名・話題などの語を、この端末に20件まで保存して再検索できます。開いた記事は通常の閲覧履歴に残ります。

## テスト

```sh
npm run build
npm run check:server
npm test
npx playwright install --with-deps chromium webkit
npm run test:e2e
npm run check:feeds
```

Chromiumのシステムパスを使う場合は `PW_SYSTEM_CHROMIUM=1`。E2Eはテスト専用データを使用し、外部フィードの障害に依存しません。実RSSは `check:feeds` で別途確認します。PWAの本番ビルド検証は `npm run test:pwa`（ビルド後）で実行します。WebKitのiPhoneエミュレーションは実機Safariの代わりにはなりません。

## デプロイ

日常利用の固定URL: **https://romnoa-syoudai1984.vercel.app/**。更新はこのURLへ反映します。デプロイごとに変わる固有URLは過去版のままです。

VercelでVite・Node.js 24のPreviewに配置します。`vercel.json` にFunction・CSP・出力先を設定済みです。**PreviewのVercel Authenticationを維持してください。本文APIはProductionでは403になります。** 一般公開前に、配信元の本文利用条件・許諾とiPhone実機チェックを確認します。設計判断は [ADR 009](docs/decisions/009-all-period-search-and-hints.md) と [ADR 005](docs/decisions/005-pickup-links-and-images.md) を参照してください。

本文は文字サイズを保ち、行間・段落間を詰めています。連続する空行は表示時だけ整理し、端末に保存済みのv3本文にも適用します。保存データの削除は不要です。


Yahoo!ニュースはホーム・検索・保存の「Yahoo!ニュース」で切替。公式RSS9カテゴリ（最大450件）の画像・記事冒頭を広告なしで表示し、Yahoo掲載中の記事の見出し/検索抜粋検索、同カテゴリ移動、保存・既読に対応します。RSS外の全文取得は行わず、全文は元記事（広告が出る場合あり）へ。新着RSS450件の絞込みに加え、人物名などはYahoo公開検索ページの先頭50候補から照合します。期間指定はせず、広告・ランキングは対象外。候補総数と取得数を区別し、未取得の続きはYahooの検索画面へ。Yahoo本文全文検索と全文のアプリ内展開は未対応です。シークレット機能は利用者の指示でソース/API/候補とも削除しました。通常のマイ検索は残っています。


Yahoo記事の写真は、記事側の大きい画像を確認して表示します。MANTANWEBの写真特集は記事の写真に続けて自動表示し、サムネイル一覧・前後・スワイプ・拡大に対応。「ニュースへ」で記事説明へすぐ移動できます。対応する記事/特集の写真だけを表示し、広告付きページの埋め込みは行いません。個人用Preview限定で、本文全文の再配信は追加していません。


Yahoo本文内のリンク先画像は、MANTANWEB以外も共通パーサーで取得します。特集という文言や配信社名で絞らず、主記事内の写真・ギャラリー領域を選び、lazy属性、srcset、OGPから抽出します。主記事の外や入れ子になった別記事の写真は混ぜません。同一ページ内の写真は重複を除いて最大40枚を切替表示します。広告・ランキング・隣の記事の領域は除外します。同一オリジン・同一ギャラリーパスの番号付き写真ページは、実在する前後リンクのみ最大40ページまで取得し、リンク先が2枚目なら2枚目から表示します。別記事へのリンクは巡回しません。JavaScript実行が必要なページやリダイレクト先の自動取得は未対応です。
